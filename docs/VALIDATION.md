- public / confidential client、刷新绑定、轮换、重复使用撤销、并发刷新和过期拒绝。
- 密钥/密码变化撤销、origin 变化拒绝、无授权族访问令牌拒绝。
- 网关与执行端均拒绝未认证请求；保留原 18 项工具及真实权限信息。
- 传统与现代协议转发、文件补丁和读取、真实命令执行、工作目录越界拒绝。
- 认证后的事件 owner 绑定、定向过滤、其他客户端无法取消订阅、撤销后停止投递。
- 签名准确字节、回调挑战、私网 DNS 和异常 URL 拒绝、游标、持久订阅与重试。
