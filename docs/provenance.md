# 来源与公开版差异

## 上游

- 项目：https://github.com/xyTom/coding-tools-mcp
- 固定依赖：PyPI `coding-tools-mcp==0.3.0`；PyJWT `2.15.1`。
- 2026-10-26 将私有部署安装目录与官方 PyPI 0.3.0 wheel 比较：15 个核心 Python
  文件逐字节相同；下载 wheel 的 SHA-256 与 PyPI 发布元数据一致。
- 本公开仓库不包含 vendor 核心副本；安装时由包管理器取得依赖。
- 文件、执行、补丁、Git、基础 OAuth/PKCE、动态注册均不声称为本项目原创。

## 私有集成中提取的扩展

- persistent_oauth.py：SQLite 客户端、授权码、授权族、刷新摘要；轮换、撤销和访问验证。
- gateway.py：OAuth 认证后转发真实执行请求。
- events.py：订阅存储、HTTPS 回调挑战、Standard Webhooks 签名、DNS/IP 校验、重试、游标。
- 相关 OAuth 与事件回归测试。

## 为公开版修改

- Python 包结构、CLI、可配置端口、路径、域名及专用进程监督。
- 执行端增加每次启动生成的 Bearer 认证，剥离网关密钥和继承的上游策略覆盖变量。
- 默认 safe，环境变量中的密钥不放进命令参数；状态目录不可位于执行工作目录内。
- 移除无授权族旧令牌的迁移兼容旁路；新安装每个访问令牌都可撤销。
- 原私有部署的事件源替换为本地 SQLite outbox；recipient 为真实认证得到的 OAuth client_id。
- 统一 UTC ISO 8601 时间；回调仅投递 id/kind/at；不保留个人身份、域名和协作接口。
- 统一网关 OAuth 与 Events，事件授权族撤销后停止投递。
- 公开包不含生产运行数据、聊天、工单、授权数据库、隧道凭据或原始历史压缩包。

## 行为边界

本版本不保留原私有部署中针对特定隧道入口的服务身份旁路，所有客户端经过同一 OAuth
网关；具体隧道的认证或 OAuth 兼容性由所选客户端和入口决定。

事件使用实验性 `2026-07-28` 协议能力；不将它宣传为所有 MCP 客户端均支持的正式能力。
不要把本集成的功能描述成上游缺少所有远程认证功能，或声称事件订阅是独家能力。
